# Shoptop প্লাগইন

ChatGPT থেকে নিজের Shoptop দোকান তৈরি ও পরিচালনার জন্য ম্যানুয়াল ইনস্টল প্যাকেজ। সেবাটি বাংলাদেশি ব্যবহারকারীদের জন্য।

## ডাউনলোড

- [shoptop.zip ডাউনলোড করুন](https://github.com/anwarulislam/shoptop-plugin/releases/download/v0.2.2/shoptop.zip)
- [GitHub Release](https://github.com/anwarulislam/shoptop-plugin/releases/tag/v0.2.2)
- [ওয়েবসাইটে বাংলায় বিস্তারিত নির্দেশনা](https://kagoj.bd/chatgpt/)
- [ওয়েবসাইট থেকে সরাসরি ZIP](https://kagoj.bd/downloads/shoptop.zip)

Release-এর Assets থেকে **shoptop.zip** নিন, স্বয়ংক্রিয়ভাবে তৈরি Source code (zip) নয়।

## ইনস্টল করার নিয়ম

1. নিজের [Shoptop অ্যাকাউন্ট](https://kagoj.bd/signup) তৈরি করুন বা লগইন করুন।
2. ব্রাউজারে ChatGPT খুলে **Plugins → + / Add → Upload plugin archive** বেছে নিন।
3. **click to upload** থেকে **shoptop.zip** নির্বাচন করে **Add plugin** চাপুন। ZIP আনজিপ করবেন না বা সাধারণ চ্যাটে attachment হিসেবে পাঠাবেন না।
4. Shoptop প্লাগইনের **Install / Connect** অপশন থাকলে চাপুন। নিজের Shoptop অ্যাকাউন্টে লগইন করে দেখানো অনুমতিগুলো পড়ে সংযোগ অনুমোদন করুন।
5. চ্যাটে Shoptop বেছে নিয়ে বলুন: “আমার দোকানের বর্তমান অবস্থা দেখাও।”

সব ChatGPT অ্যাকাউন্টে ZIP আপলোড থাকে না। আপনার প্ল্যান, অ্যাকাউন্ট ও workspace-এর অনুমতির ওপর সুবিধাটি নির্ভর করে। ZIP ডাউনলোড করলেই এই সুবিধা চালু হয় না। বোতামের নাম বা অবস্থান আলাদা হতে পারে। [OpenAI-এর নির্দেশনা](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt) দেখুন অথবা workspace admin-এর সঙ্গে যোগাযোগ করুন।

এটি ব্যক্তিগতভাবে ইনস্টলের প্যাকেজ; ChatGPT-এর পাবলিক ডিরেক্টরিতে অনুমোদিত তালিকা নয়।

## কী করা যায়

দোকান তৈরি, পণ্য ও স্টক পরিচালনা, অর্ডার দেখা, বিক্রির হিসাব এবং storefront সম্পাদনা। সংযোগ দোকানের তথ্য পড়তে ও বদলাতে পারে; Shoptop ড্যাশবোর্ডের AI Connections থেকে সংযোগ বাতিল করা যায়।

Shoptop-এ সাইট তৈরি ও পরিচালনা বর্তমানে বিনামূল্যে; ভবিষ্যতে ঐচ্ছিক Pro প্ল্যান আসতে পারে। Shoptop নিজে পণ্য বিক্রি করে না। স্বাধীন বিক্রেতারা কেবল বাস্তব, ডেলিভারিযোগ্য পণ্য বিক্রি করেন। ক্রেতা ChatGPT-এর বাইরে বিক্রেতাকে মূল্য পরিশোধ করেন। প্লাগইন টাকা পাঠানো, রিফান্ড, SMS বা কুরিয়ার বুকিং করে না।
